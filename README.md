# DB-Query-LLM-Agent

### About
- DB Query LLM Agent is a local tool that lets you query SQLite databases using normal English prompts.
- It looks at your `.db` file schema, generates the SQL query, runs it locally, and gives you a clear human-readable answer instead of raw database rows.
- Everything runs locally

### Features
- Plain English to SQL conversion
- Returns clear written answers based on query output
- Automatic schema and sample data inspection
- Fully offline and local-only

### Tech Stack
- Python
- Ollama (Gemma-3:4b)
- SQLite3
- uv - packaging
